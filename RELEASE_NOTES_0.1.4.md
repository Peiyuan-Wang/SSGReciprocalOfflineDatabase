# SSG Reciprocal Offline Database 0.1.4

- The overview displays the spatial sublattice `Z_{L_0}` of the unitary
  translation center `Z_{T_0}`. Its reciprocal lattice is `L_F`.
- Reciprocal records now expose `ZL0` and `ZL0Convention`, consistent with
  Mathematica package 0.12.0 and the manuscript.
- The scientific records for all 67,475 SSGs and the MNG reverse searches
  are unchanged. Database schema version 3 uses the updated field names.
- Download the matching 0.1.4 viewer and database; macOS and Windows viewers
  use the same scientific records.
