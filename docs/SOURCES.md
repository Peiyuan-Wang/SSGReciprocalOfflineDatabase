# Data Sources

The SQLite database is generated from the scientific records distributed by
the [MG Computational Package](https://github.com/Peiyuan-Wang/SSGReciprocalDatabase).
It preserves the reciprocal records, O(3) representations, standard-group
identifications, and BNS-to-SSG links.

SSG labels follow Xiao et al., *Spin Space Groups: Full Classification and
Applications*, Physical Review X 14, 031037 (2024):
https://doi.org/10.1103/PhysRevX.14.031037 .

The computational package's [source description](https://github.com/Peiyuan-Wang/SSGReciprocalDatabase/blob/main/docs/SOURCES.md)
records the ISO-IR, spglib, and operation-name sources. Code and data licensing
are separate from attribution of these third-party sources.
